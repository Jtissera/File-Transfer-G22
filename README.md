## Descripción Breve del Proyecto

Este proyecto tiene como objetivo la creación de una aplicación de red de arquitectura cliente - servidor que implemente la funcionalidad de transferencia de archivos confiable utilizando el protocolo de capa de transporte UDP.

Para asegurar la transferencia confiable de archivos se implemento una versión utilizando el protocolo Stop and Wait y otra versión utilizando el mecanismo de error-recovery de Go-Back-N
